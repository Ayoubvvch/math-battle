## 🎮 The Premise
Inside an orthonormal Cartesian coordinate plane, the fundamental mathematical operator of calculus: **$\frac{d}{dx}$ (The Derivative)** wages an eternal war against algebraic and trigonometric functions.

Every time $\frac{d}{dx}$ collides with an orb, it mathematically differentiates it:
- **$\frac{d}{dx}(x^3) = 3x^2$** $\to$ splits into 3 smaller parabolas
- **$\frac{d}{dx}(x^2) = 2x$** $\to$ splits into 2 linear orbs
- **$\frac{d}{dx}(x) = 1$** $\to$ transforms into a constant 1
- **$\frac{d}{dx}(1) = 0$** $\to$ annihilates into sparkling particles!

### ⚔️ Battle Roster:
1. **$\frac{d}{dx}$ VS $x^3$** (Classic Cubic Duel - 16 differentiations)
2. **$\frac{d}{dx}$ VS $x^4$** (Quartic Chaos Swarm - 65 orbs!)
3. **$\frac{d}{dx}$ VS $\sin(x)$** (Trigonometric Cycle: $\sin \to \cos \to -\sin \to -\cos \to 0$)
4. **$\frac{d}{dx}$ VS $e^x$** (The Immortal Singularity: $\frac{d}{dx}e^x = e^x$, fractures into copies until broken!)
